Insidous Rust adventures in C wonderland

- hello: Rust and C FFI interleaving with callback functions
- state: Sharing atomic and thread-local data between Rust and C
- factorial: Using mini-gmp C library to calculate large factorials
- errno: Error handling across FFI boundary with errno and strerror (Linux-only)
- dist: Passing Rust callbacks to C's qsort function

Run with make <target>
